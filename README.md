Laptop Diagnostic Tool 🖥️

A free, PowerShell-based diagnostic tool for Windows laptops and PCs.

Generate a detailed report covering hardware, battery health, storage devices, system event errors, drivers, Windows activation, security settings, and installed applications.

Features :
- Hardware and system information
- Battery health and capacity report
- Disk and storage status checks
- Windows system event error collection
- Driver and installed software inventory
- Windows activation and security status
- Exportable diagnostic reports

Goal :
Help users understand their computer's condition, troubleshoot common problems, and collect useful diagnostic information without manually running multiple commands.

**Disclaimer:** This tool collects diagnostic information; it does not guarantee detection of every hardware fault. Back up important files before attempting repairs. Review reports for personal information before sharing them publicly / AI.
